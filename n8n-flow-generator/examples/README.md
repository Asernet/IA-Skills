# n8n Workflow Examples

Questa cartella contiene esempi di workflow n8n in formato JSON.
La skill `n8n-flow-generator` utilizzerà questi file come riferimento (Few-Shot Learning) per migliorare la generazione di nuovi workflow.

## Come aggiungere un nuovo esempio

1.  Esporta il workflow da n8n (o copialo come JSON).
2.  Assicurati che sia leggibile e ben formattato.
3.  Salvalo in questa cartella con un nome descrittivo, es: `webhook_to_notion.json`.
4.  (Opzionale) Aggiungi un file `.txt` o `.md` con lo stesso nome per spiegare il contesto se non è chiaro dal JSON.
