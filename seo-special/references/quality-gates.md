## Soglie per le Pagine di Località

### Livello di Avviso (30+ pagine)

- ⚠️ **AVVISO** a 30+ pagine di località
- Imporre oltre il 60% di contenuto unico per pagina
- Il contenuto deve includere:
  - Informazioni locali uniche (punti di riferimento, quartieri)
  - Servizi o offerte specifici per la località
  - Membri del team o personale locale
  - Testimonianze reali di clienti di quell'area

### Blocco (50+ pagine)

- 🛑 **STOP** a 50+ pagine di località
- Richiedere una giustificazione esplicita dell'utente
- Deve dimostrare:
  - Presenza commerciale legittima in ogni località
  - Strategia di contenuto unico per ogni pagina
  - Segnali locali (Google Business Profile, recensioni locali)

### Perché è Importante

L'algoritmo di Google per le "doorway page" penalizza le pagine di località programmatiche con contenuti scarsi o duplicati. Segnali di doorway page:

- Solo il nome della città/stato è cambiato tra le pagine
- Nessuna informazione locale unica
- Nessun segnale di business locale
- URL pieni di parole chiave (keyword-stuffed)

## Pagine Programmatiche: Sicure vs. Rischiose

### Sicure su Scala ✅

| Tipo di Pagina               | Perché è Sicura                                                 |
| ---------------------------- | --------------------------------------------------------------- |
| Pagine di integrazione       | Documentazione reale di configurazione, contenuto tecnico unico |
| Pagine di template/strumenti | Risorse scaricabili, funzionalità unica                         |
| Pagine di glossario          | Definizioni uniche di oltre 200 parole                          |
| Pagine prodotto              | Specifiche uniche, immagini, recensioni                         |
| Pagine profilo utente        | Contenuto unico generato dagli utenti                           |

### Rischio di Penalizzazione ❌

| Tipo di Pagina                           | Perché è Rischiosa                                    |
| ---------------------------------------- | ----------------------------------------------------- |
| Pagine località con solo città scambiata | Contenuto duplicato, doorway page                     |
| "Miglior [strumento] per [settore]"      | Spesso scarno, nessun valore specifico per il settore |
| "Alternativa a [Competitor]"             | Richiede dati di confronto reali                      |
| Contenuto di massa generato dall'AI      | Nessun valore unico, fallimento E-E-A-T               |

## Requisiti dei Tag Title

| Aspetto                | Requisito                              |
| ---------------------- | -------------------------------------- |
| Lunghezza minima       | 30 caratteri                           |
| Lunghezza massima      | 60 caratteri (Google taglia a ~60)     |
| Parola chiave primaria | Vicino all'inizio                      |
| Nome del brand         | Alla fine (se incluso)                 |
| Unicità                | Ogni pagina deve avere un titolo unico |

### Esempi Corretti

- "Servizi Idraulici di Emergenza a Austin | ABC Plumbing"
- "Come Riparare un Rubinetto che Perde: Guida Passo-Passo"
- "Software SEO Enterprise | Piattaforma Completa"

### Esempi Errati

- "Home" (troppo breve, non descrittivo)
- "Migliori Servizi Idraulici per Tutte le Tue Esigenze Idrauliche ad Austin Texas e Aree Limitrofe" (troppo lungo)
- "ABC Plumbing - Idraulica - Idraulico - Servizi Idraulici" (keyword stuffing)

## Requisiti delle Meta Description

| Aspetto                | Requisito                                    |
| ---------------------- | -------------------------------------------- |
| Lunghezza minima       | 120 caratteri                                |
| Lunghezza massima      | 160 caratteri (Google taglia a ~155-160)     |
| Chiamata all'azione    | Includere una CTA convincente                |
| Parola chiave primaria | Includere in modo naturale                   |
| Unicità                | Ogni pagina deve avere una descrizione unica |

---

## Requisiti del Testo Alt delle Immagini

| Aspetto             | Requisito                                                                |
| ------------------- | ------------------------------------------------------------------------ |
| Obbligatorio su     | Tutte le immagini non decorative                                         |
| Lunghezza           | 10-125 caratteri                                                         |
| Contenuto           | Descrivere il contenuto dell'immagine, non "immagine" o il nome del file |
| Parole chiave       | Includere in modo naturale dove pertinente                               |
| Immagini decorative | Usare `alt=""` o `role="presentation"`                                   |

### Esempi Corretti

- "Idraulico professionista che ripara il rubinetto del lavello della cucina"
- "Vista frontale della berlina Toyota Camry rossa del 2024"
- "Incontro del team nella sala conferenze di un ufficio moderno"

### Esempi Errati

- "immagine.jpg" (nome file, non descrizione)
- "idraulico idraulica servizi idraulici" (keyword stuffing)
- "Clicca qui" (non descrittivo)

## Linee Guida per il Linking Interno

| Tipo di Pagina                | Destinazione Link Interni   |
| ----------------------------- | --------------------------- |
| Post del blog (1.500+ parole) | 5-10 link interni           |
| Pagina servizio               | 3-5 link interni            |
| Pagina categoria              | Link a tutte le sottopagine |
| Pagina prodotto               | 2-4 link interni            |

### Regole per il Testo di Ancoraggio (Anchor Text)

- Usare testo di ancoraggio descrittivo (non "clicca qui")
- Variare il testo di ancoraggio (non usare sempre parole chiave a corrispondenza esatta)
- Collegare a contenuti pertinenti e correlati
- Assicurarsi che non ci siano pagine orfane (ogni pagina deve essere collegata da almeno un'altra)

## Segnali di Freschezza del Contenuto

| Tipo di Contenuto         | Frequenza di Aggiornamento    |
| ------------------------- | ----------------------------- |
| Notizie/eventi attuali    | Entro ore/giorni              |
| Post del blog (evergreen) | Revisione annuale             |
| Pagine prodotto           | Quando cambiano le specifiche |
| Pagine di servizio        | Revisione trimestrale         |
| Info aziendali            | Quando avvengono cambiamenti  |

### Elementi Richiesti

- Data di pubblicazione visibile (per articoli/blog)
- Data di ultimo aggiornamento (se revisionato in modo significativo)
- Changelog per aggiornamenti principali (opzionale ma consigliato)
