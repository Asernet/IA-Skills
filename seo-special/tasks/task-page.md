# Analisi SEO On-Page

## Elementi Analizzati

1. **Tag Title:** Lunghezza (50-60 caratteri), presenza keyword primaria a sinistra.
2. **Meta Description:** Lunghezza (120-150 caratteri), CTA inclusa, pertinenza.
3. **Gerarchia Heading:** Struttura H1 (unico) -> H2 -> H3 logica e coerente.
4. **Internal Linking:** Presenza di anchor text descrittivi verso pagine correlate.
5. **Sintassi HTML:** Verifica errori che potrebbero ostacolare i crawler.

## Formato Report

- **Checklist On-Page:** Stato per ogni elemento.
- **Snippet Preview:** Simulazione visualizzazione nei risultati di ricerca.
- **Miglioramenti Testuali:** Proposte di revisione per Title e Meta.
