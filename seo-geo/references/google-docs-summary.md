# Riepilogo Documentazione Ufficiale SEO di Google

Riferimento rapido da Google Search Central.

---

## Processo di Ricerca in Tre Fasi

| Fase                          | Descrizione                                 | Focus                      |
| ----------------------------- | ------------------------------------------- | -------------------------- |
| **Scansione (Crawling)**      | Googlebot scopre le pagine                  | robots.txt, sitemap, link  |
| **Indicizzazione (Indexing)** | Il contenuto viene analizzato e memorizzato | Qualità, canonica, noindex |
| **Pubblicazione (Serving)**   | I risultati vengono restituiti              | Rilevanza, E-E-A-T, UX     |

---

## Core Web Vitals

| Metrica | Buona   | Necessita Miglioramento | Scarsa  |
| ------- | ------- | ----------------------- | ------- |
| **LCP** | < 2.5s  | 2.5-4s                  | > 4s    |
| **FID** | < 100ms | 100-300ms               | > 300ms |
| **CLS** | < 0.1   | 0.1-0.25                | > 0.25  |

## Tipi di Dati Strutturati

| Tipo           | Caso d'Uso    | Risultato Multimediale |
| -------------- | ------------- | ---------------------- |
| FAQPage        | Contenuti FAQ | D&R espandibili        |
| Article        | Blog/notizie  | Titolo + data          |
| Product        | E-commerce    | Prezzo + valutazione   |
| HowTo          | Tutorial      | Passaggi               |
| VideoObject    | Video         | Miniatura              |
| BreadcrumbList | Navigazione   | Breadcrumb (Percorsi)  |

---

## Politiche Spam (Da Evitare)

- Keyword stuffing
- Testi/link nascosti
- Schemi di link
- Contenuti generati automaticamente
- Contenuti copiati (scraped)
- Cloaking
