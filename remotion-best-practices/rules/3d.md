# Uso di Three.js e React Three Fiber in Remotion

Segui le best practice di React Three Fiber e Three.js.  
Devono essere seguite solo le seguenti regole specifiche per Remotion:

## Prerequisiti

Innanzitutto, deve essere installato il pacchetto `@remotion/three`.  
Se non lo è, usa il seguente comando:

```bash
npx remotion add @remotion/three # Se il progetto usa npm
bunx remotion add @remotion/three # Se il progetto usa bun
yarn remotion add @remotion/three # Se il progetto usa yarn
pnpm exec remotion add @remotion/three # Se il progetto usa pnpm
```

## Utilizzo di ThreeCanvas

DEVI avvolgere i contenuti 3D in `<ThreeCanvas>` e includere un'illuminazione adeguata.  
`<ThreeCanvas>` DEVE avere le prop `width` e `height`.

```tsx
import { ThreeCanvas } from "@remotion/three";
import { useVideoConfig } from "remotion";

const { width, height } = useVideoConfig();

<ThreeCanvas width={width} height={height}>
  <ambientLight intensity={0.4} />
  <directionalLight position={[5, 5, 5]} intensity={0.8} />
  <mesh>
    <sphereGeometry args={[1, 32, 32]} />
    <meshStandardMaterial color="red" />
  </mesh>
</ThreeCanvas>;
```

## Nessuna animazione non guidata da `useCurrentFrame()`

Shader, modelli ecc. NON DEVONO animarsi da soli.  
Non sono consentite animazioni a meno che non siano guidate da `useCurrentFrame()`.  
In caso contrario, causerebbero sfarfallio (flickering) durante il rendering.

L'uso di `useFrame()` da `@react-three/fiber` è vietato.

## Animare usando `useCurrentFrame()`

Usa `useCurrentFrame()` per eseguire le animazioni.

```tsx
const frame = useCurrentFrame();
const rotationY = frame * 0.02;

<mesh rotation={[0, rotationY, 0]}>
  <boxGeometry args={[2, 2, 2]} />
  <meshStandardMaterial color="#4a9eff" />
</mesh>;
```

## Utilizzo di `<Sequence>` dentro `<ThreeCanvas>`

La prop `layout` di qualsiasi `<Sequence>` all'interno di un `<ThreeCanvas>` deve essere impostata su `none`.

```tsx
import { Sequence } from "remotion";
import { ThreeCanvas } from "@remotion/three";

const { width, height } = useVideoConfig();

<ThreeCanvas width={width} height={height}>
  <Sequence layout="none">
    <mesh>
      <boxGeometry args={[2, 2, 2]} />
      <meshStandardMaterial color="#4a9eff" />
    </mesh>
  </Sequence>
</ThreeCanvas>;
```
